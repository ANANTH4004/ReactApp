# Forms in React

Forms in React are used to collect user input. React manages form data using **controlled components**, where the form values are stored in the component's state (using `useState`). This makes it easy to update and validate input as the user types.

**Validation** checks if the input meets certain rules before allowing submission. You can write your own validation logic or use libraries.

**Submission** is handled by the `onSubmit` event, which processes the form data.

React forms give you full control over input, validation, and submission.
